# Smart Label Compliance Checker 🔍

A mobile-friendly web application designed for automated OCR-based label compliance verification. The app checks food and commercial product labels against mandatory regulatory standards.

## 🚀 Live Demo
Access the live application here:  
👉 **[https://anujanifar-g.github.io/Smart-label-checker/](https://anujanifar-g.github.io/Smart-label-checker/)**

## ✨ Features
- **Real-Time Label Scanning:** Mobile camera integration for quick image capture.
- **Compliance Parameters Verified:**
  - 🟢 **Dietary Indicator** (Veg/Non-Veg symbol detection)
  - 📋 **Ingredients & Allergens** list verification
  - 📜 **FSSAI License** number validation
  - 💰 **MRP** (Inclusive of all taxes)
  - ⚖️ **Net Quantity / Weight**
  - 📅 **Expiry / Date Coding**
- **Image Controls:** Built-in options to rotate image (90° / 180°) for better OCR accuracy.
- **Binary Status:** Instant COMPLIANT or NON-COMPLIANT assessment.
